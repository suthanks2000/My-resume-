## Build and check workflow
1. Generate the .docx with python-docx or docx (npm) from this file; export PDF with LibreOffice (`soffice --headless --convert-to pdf`).
2. Verify: exactly 1 page (`pdfinfo`), text selectable (`pdftotext`), no tables, fonts embedded.
3. Keyword test: compare resume text against the pasted JD keywords, report match %, list missing keywords the owner genuinely has.
4. Review as three readers and list flaws: ATS machine, HR recruiter (6-second scan), 30-year mentor / hiring manager.
5. Save outputs as `Suthan_K_Resume_<Role>.docx/.pdf`. Never overwrite the previous version; keep `v1`, `v2` copies.

## Build environment note (added by Claude, 2026-10-24)
LibreOffice is not available on this box (Amazon Linux 2023, arm64 - no package in repos), so the
PDF is generated directly with ReportLab using the same layout rules instead of converting the
.docx. Arial is not installed either; Liberation Sans (metric-compatible with Arial) renders the
PDF, while the .docx requests "Arial" by name so Word/ATS sees Arial.
